Event Rounds

Participants will go through three challenging rounds to prove their coding prowess.
1. Debugging Round
It's pretty self explanatory you will be given bugged codes to fix.

2. Blind Coding
You will have to write a simple program without seeing keyboard or anything while being blindfolded

3. Code Clash
For the last round you will be given a question and not only you have to use coding skills but critical thinking to find and algorithm and code it as well.

Event Rules
